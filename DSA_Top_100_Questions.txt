# Top 100 Most-Asked DSA Interview Questions

## ARRAYS & HASHING
============================================================
1.  Two Sum (Easy) — hash map of complements (target - num). → O(n) / O(n)
2.  Best Time to Buy & Sell Stock (Easy) — track min price, max profit. → O(n) / O(1)
3.  Contains Duplicate (Easy) — store seen in a Set. → O(n) / O(n)
4.  Valid Anagram (Easy) — char-frequency count match. → O(n) / O(1)
5.  Group Anagrams (Medium) — key = sorted word / char-count, hashmap. → O(n·k) / O(n)
6.  Top K Frequent Elements (Medium) — frequency map + bucket sort / heap. → O(n) / O(n)
7.  Product of Array Except Self (Medium) — prefix × suffix products. → O(n) / O(1)
8.  Encode & Decode Strings (Medium) — length-prefix each string. → O(n) / O(n)
9.  Longest Consecutive Sequence (Medium) — Set; start counting only at sequence starts. → O(n) / O(n)
10. Maximum Subarray / Kadane's (Medium) — running sum, reset when negative. → O(n) / O(1)
11. Maximum Product Subarray (Medium) — track running max AND min (negatives). → O(n) / O(1)

## QUICK REVISION TIPS
============================================================
- Each problem maps to a PATTERN — learn the pattern, not the problem.
- Always state brute force first, then optimize (usually with hashing/two-pointers/DP).
- Clarify input constraints → they hint the target complexity.
- For trees/graphs: decide DFS vs BFS early.
- For "min/max/number of ways" → think DP. For "sorted / search space" → think binary search.
- Re-derive complexity out loud; mention space too.

Recommended order: Arrays/Hashing → Two Pointers → Sliding Window → Stack → Binary
Search → Linked List → Trees → Tries → Heap → Backtracking → Graphs → Intervals → DP.
