# Data Structures & Algorithms — In-Depth Notes (Basics → Advanced)

> Examples are in JavaScript. Read top-to-bottom; each topic builds on the previous.

## 0. How to Use These Notes
- **Learn the idea**, then the **complexity**, then **code it from memory**.
- For every structure ask: *How do I insert / delete / search / traverse, and at what cost?*
- Master patterns (two pointers, sliding window, BFS/DFS, DP) — most problems are variations.

## 1. Complexity Analysis (Big-O)

Big-O describes how runtime/memory **grows** as input size `n` grows (worst case).

| Notation | Name | Example |
|----------|------|---------|
| O(1) | Constant | array index access |
| O(log n) | Logarithmic | binary search |
| O(n) | Linear | loop over array |
| O(n log n) | Linearithmic | merge/quick sort |
| O(n²) | Quadratic | nested loops |
| O(2ⁿ) | Exponential | naive recursion (subsets) |
| O(n!) | Factorial | permutations |

**Rules:** drop constants (`O(2n)→O(n)`), keep the dominant term (`O(n²+n)→O(n²)`).

```js
// O(n) time, O(1) space
function sum(arr) {
  let total = 0;            // O(1) space
  for (const x of arr) total += x; // O(n) time
  return total;
}
```

**Space complexity** = extra memory used (recursion stack counts!).

## 2. Arrays

Contiguous memory, **O(1) random access** by index.

- Access: **O(1)** | Search: **O(n)** | Insert/Delete (middle): **O(n)** | Push/Pop (end): **O(1)**

```js
const a = [10, 20, 30];
a[1];           // 20  (O(1))
a.push(40);     // add end O(1)
a.pop();        // remove end O(1)
a.unshift(5);   // add front O(n)
a.splice(1, 1); // remove index 1 O(n)
```

**Common techniques:** prefix sums, two pointers, sliding window, hashing.

```js
// Prefix sum: range sum queries in O(1) after O(n) build
function prefix(arr) {
  const p = [0];
  for (let i = 0; i < arr.length; i++) p[i + 1] = p[i] + arr[i];
  return p; // sum(l..r) = p[r+1] - p[l]
}
```

## 3. Two Pointers

Use two indices moving toward/with each other — turns many O(n²) into **O(n)**.

```js
// Pair with given sum in a SORTED array
function twoSumSorted(arr, target) {
  let l = 0, r = arr.length - 1;
  while (l < r) {
    const s = arr[l] + arr[r];
    if (s === target) return [l, r];
    s < target ? l++ : r--;
  }
  return null;
}
```

Also used for: reversing, removing duplicates, merging sorted arrays, palindrome check.

---

## 4. Sliding Window

A moving sub-array/window — great for **subarray/substring** problems.

```js
// Max sum of subarray of size k — O(n)
function maxWindow(arr, k) {
  let sum = 0, max = -Infinity;
  for (let i = 0; i < arr.length; i++) {
    sum += arr[i];
    if (i >= k - 1) { max = Math.max(max, sum); sum -= arr[i - k + 1]; }
  }
  return max;
}

// Longest substring without repeating chars — variable window
function longestUnique(s) {
  const seen = new Map();
  let start = 0, best = 0;
  for (let i = 0; i < s.length; i++) {
    if (seen.has(s[i]) && seen.get(s[i]) >= start) start = seen.get(s[i]) + 1;
    seen.set(s[i], i);
    best = Math.max(best, i - start + 1);
  }
  return best;
}
```

## 5. Strings

Immutable in JS. Key ops: split, reverse, compare, char frequency.

```js
// Anagram check — O(n) using frequency map
function isAnagram(a, b) {
  if (a.length !== b.length) return false;
  const count = {};
  for (const c of a) count[c] = (count[c] || 0) + 1;
  for (const c of b) {
    if (!count[c]) return false;
    count[c]--;
  }
  return true;
}
```

**Patterns:** sliding window, two pointers, hashing, tries, KMP (pattern matching).

## 6. Hashing (Hash Tables / Maps)

Key → value with **average O(1)** insert/search/delete. JS: `Object`, `Map`, `Set`.

```js
// Two Sum — O(n) using a hash map
function twoSum(nums, target) {
  const seen = new Map();
  for (let i = 0; i < nums.length; i++) {
    const need = target - nums[i];
    if (seen.has(need)) return [seen.get(need), i];
    seen.set(nums[i], i);
  }
}
```

- **Collisions** handled via chaining (linked lists) or open addressing.
- Use **Set** for uniqueness, **Map** for key→value with any key type & order.

## 7. Recursion

A function calling itself with a **base case** + **smaller subproblem**.

```js
function factorial(n) {
  if (n <= 1) return 1;        // base case
  return n * factorial(n - 1); // recursive case
}
```

- Each call adds a **stack frame** → space O(depth).
- **Tail recursion**: recursive call is the last action (can be optimized in some langs).
- Watch for stack overflow on deep recursion — convert to iteration if needed.

## 8. Linked Lists

Nodes linked by pointers. **No random access**, but O(1) insert/delete at known position.

```js
class Node {
  constructor(val) { this.val = val; this.next = null; }
}

// Reverse a singly linked list — O(n) time, O(1) space
function reverse(head) {
  let prev = null, curr = head;
  while (curr) {
    const next = curr.next;
    curr.next = prev;
    prev = curr;
    curr = next;
  }
  return prev;
}
```

| Type | Notes |
|------|-------|
| Singly | one `next` pointer |
| Doubly | `next` + `prev` (easier deletion) |
| Circular | last node points to head |

**Patterns:** fast/slow pointers (cycle detection, middle), dummy head.

```js
// Floyd's cycle detection
function hasCycle(head) {
  let slow = head, fast = head;
  while (fast && fast.next) {
    slow = slow.next; fast = fast.next.next;
    if (slow === fast) return true;
  }
  return false;
}
```

## 9. Stacks (LIFO)

Last-In-First-Out. Push/Pop/Peek = **O(1)**. (JS array works as a stack.)

```js
const stack = [];
stack.push(1); stack.push(2);
stack.pop();   // 2
stack[stack.length - 1]; // peek

// Valid parentheses — classic stack problem
function isValid(s) {
  const pairs = { ")": "(", "]": "[", "}": "{" };
  const st = [];
  for (const c of s) {
    if (c in pairs) { if (st.pop() !== pairs[c]) return false; }
    else st.push(c);
  }
  return st.length === 0;
}
```

**Uses:** undo, expression evaluation, DFS, backtracking, function call stack, monotonic stack.

## 10. Queues (FIFO)

First-In-First-Out. Enqueue/Dequeue = **O(1)** (use a real queue, not `array.shift()` which is O(n)).

```js
class Queue {
  constructor() { this.items = {}; this.front = 0; this.back = 0; }
  enqueue(x) { this.items[this.back++] = x; }
  dequeue() { const x = this.items[this.front]; delete this.items[this.front++]; return x; }
  isEmpty() { return this.front === this.back; }
}
```

- **Deque** — insert/remove both ends.
- **Circular queue** — fixed-size buffer reusing slots.
- **Priority queue** — served by priority (use a heap).

**Uses:** BFS, scheduling, buffering, rate limiting.

## 11. Searching

```js
// Linear search — O(n)
function linear(arr, x) {
  for (let i = 0; i < arr.length; i++) if (arr[i] === x) return i;
  return -1;
}

// Binary search — O(log n) on a SORTED array
function binary(arr, x) {
  let lo = 0, hi = arr.length - 1;
  while (lo <= hi) {
    const mid = (lo + hi) >> 1;       // floor((lo+hi)/2)
    if (arr[mid] === x) return mid;
    arr[mid] < x ? (lo = mid + 1) : (hi = mid - 1);
  }
  return -1;
}
```

**Binary search variants:** first/last occurrence, lower/upper bound, search in rotated array, "binary search on answer".

## 12. Sorting

| Algorithm | Best | Avg | Worst | Space | Stable |
|-----------|------|-----|-------|-------|--------|
| Bubble | O(n) | O(n²) | O(n²) | O(1) | yes |
| Selection | O(n²) | O(n²) | O(n²) | O(1) | no |
| Insertion | O(n) | O(n²) | O(n²) | O(1) | yes |
| Merge | O(n log n) | O(n log n) | O(n log n) | O(n) | yes |
| Quick | O(n log n) | O(n log n) | O(n²) | O(log n) | no |
| Heap | O(n log n) | O(n log n) | O(n log n) | O(1) | no |
| Counting | O(n+k) | O(n+k) | O(n+k) | O(k) | yes |

```js
// Merge sort — divide & conquer, O(n log n)
function mergeSort(arr) {
  if (arr.length <= 1) return arr;
  const mid = arr.length >> 1;
  const left = mergeSort(arr.slice(0, mid));
  const right = mergeSort(arr.slice(mid));
  const res = [];
  let i = 0, j = 0;
  while (i < left.length && j < right.length)
    res.push(left[i] <= right[j] ? left[i++] : right[j++]);
  return [...res, ...left.slice(i), ...right.slice(j)];
}

// Quick sort — pivot partition, avg O(n log n)
function quickSort(arr) {
  if (arr.length <= 1) return arr;
  const pivot = arr[arr.length - 1];
  const left = arr.filter((x, i) => x < pivot && i < arr.length - 1);
  const right = arr.filter((x) => x >= pivot).slice(0, -1);
  return [...quickSort(left), pivot, ...quickSort(right)];
}
```

## 13. Trees

Hierarchical: a root with children. **Binary tree** = ≤ 2 children per node.

```js
class TreeNode {
  constructor(val) { this.val = val; this.left = this.right = null; }
}
```

### Traversals (DFS)
```js
function inorder(node, res = []) {   // Left, Root, Right  (sorted for BST)
  if (!node) return res;
  inorder(node.left, res);
  res.push(node.val);
  inorder(node.right, res);
  return res;
}
// preorder  = Root, Left, Right   (copy a tree)
// postorder = Left, Right, Root   (delete a tree)
```

### Level-order (BFS)
```js
function levelOrder(root) {
  if (!root) return [];
  const res = [], q = [root];
  while (q.length) {
    const level = [];
    for (let i = q.length; i > 0; i--) {
      const n = q.shift();
      level.push(n.val);
      if (n.left) q.push(n.left);
      if (n.right) q.push(n.right);
    }
    res.push(level);
  }
  return res;
}
```

### Binary Search Tree (BST)
Left subtree < node < right subtree → search/insert/delete **O(h)** (h = height).

```js
function insertBST(root, val) {
  if (!root) return new TreeNode(val);
  if (val < root.val) root.left = insertBST(root.left, val);
  else root.right = insertBST(root.right, val);
  return root;
}
```

- **Balanced** BST (AVL, Red-Black) keeps `h = O(log n)`.
- Unbalanced BST can degrade to O(n) (a linked list).

## 14. Heaps / Priority Queue

Complete binary tree where parent ≤ children (**min-heap**) or ≥ (**max-heap**).
Insert/Extract = **O(log n)**, Peek = **O(1)**. Stored in an array.

```js
class MinHeap {
  constructor() { this.h = []; }
  push(v) {
    this.h.push(v);
    let i = this.h.length - 1;
    while (i > 0) {
      const p = (i - 1) >> 1;
      if (this.h[p] <= this.h[i]) break;
      [this.h[p], this.h[i]] = [this.h[i], this.h[p]];
      i = p;
    }
  }
  pop() {
    const top = this.h[0], last = this.h.pop();
    if (this.h.length) {
      this.h[0] = last;
      let i = 0;
      while (true) {
        let s = i, l = 2 * i + 1, r = 2 * i + 2;
        if (l < this.h.length && this.h[l] < this.h[s]) s = l;
        if (r < this.h.length && this.h[r] < this.h[s]) s = r;
        if (s === i) break;
        [this.h[s], this.h[i]] = [this.h[i], this.h[s]];
        i = s;
      }
    }
    return top;
  }
}
```

**Uses:** priority queue, Dijkstra, top-K elements, median of stream, scheduling.

## 15. Trie (Prefix Tree)

Tree for storing strings by characters — fast **prefix** search.
Insert/Search = **O(L)** where L = word length.

```js
class Trie {
  constructor() { this.root = {}; }
  insert(word) {
    let node = this.root;
    for (const c of word) node = node[c] ??= {};
    node.isEnd = true;
  }
  search(word) {
    let node = this.root;
    for (const c of word) { if (!node[c]) return false; node = node[c]; }
    return !!node.isEnd;
  }
  startsWith(prefix) {
    let node = this.root;
    for (const c of prefix) { if (!node[c]) return false; node = node[c]; }
    return true;
  }
}
```

**Uses:** autocomplete, spell-check, IP routing, dictionary.

## 16. Graphs

Nodes (vertices) + edges. Directed/undirected, weighted/unweighted.

**Representations:**
```js
// Adjacency list (most common) — O(V + E) space
const graph = {
  A: ["B", "C"],
  B: ["A", "D"],
  C: ["A"],
  D: ["B"],
};
```

### BFS (shortest path in unweighted graph)
```js
function bfs(graph, start) {
  const visited = new Set([start]), q = [start], order = [];
  while (q.length) {
    const node = q.shift();
    order.push(node);
    for (const nb of graph[node]) {
      if (!visited.has(nb)) { visited.add(nb); q.push(nb); }
    }
  }
  return order;
}
```

### DFS
```js
function dfs(graph, node, visited = new Set(), order = []) {
  visited.add(node);
  order.push(node);
  for (const nb of graph[node])
    if (!visited.has(nb)) dfs(graph, nb, visited, order);
  return order;
}
```

### Topological Sort (DAG ordering — e.g., task scheduling)
```js
function topoSort(graph) {
  const visited = new Set(), stack = [];
  function dfs(n) {
    visited.add(n);
    for (const nb of graph[n]) if (!visited.has(nb)) dfs(nb);
    stack.push(n);
  }
  for (const n in graph) if (!visited.has(n)) dfs(n);
  return stack.reverse();
}
```

### Dijkstra (shortest path, weighted, non-negative) — O((V+E) log V)
```js
function dijkstra(graph, start) {
  // graph[node] = [[neighbor, weight], ...]
  const dist = {}; for (const n in graph) dist[n] = Infinity;
  dist[start] = 0;
  const pq = [[0, start]]; // [distance, node]
  while (pq.length) {
    pq.sort((a, b) => a[0] - b[0]);       // (use a real heap for efficiency)
    const [d, node] = pq.shift();
    if (d > dist[node]) continue;
    for (const [nb, w] of graph[node]) {
      if (d + w < dist[nb]) { dist[nb] = d + w; pq.push([dist[nb], nb]); }
    }
  }
  return dist;
}
```

**Other key graph algos:**
- **Union-Find (DSU)** — connected components, cycle detection (below).
- **MST** — Kruskal (sort edges + DSU) / Prim (greedy + heap).
- **Bellman-Ford** — shortest path with negative weights.
- **Floyd-Warshall** — all-pairs shortest path, O(V³).

### Union-Find (Disjoint Set)
```js
class DSU {
  constructor(n) { this.parent = [...Array(n).keys()]; }
  find(x) { return this.parent[x] === x ? x : (this.parent[x] = this.find(this.parent[x])); }
  union(a, b) { this.parent[this.find(a)] = this.find(b); }
  connected(a, b) { return this.find(a) === this.find(b); }
}
```

## 17. Recursion → Dynamic Programming (DP)

DP = solve overlapping subproblems once and **store** results.
Two styles: **Memoization** (top-down) and **Tabulation** (bottom-up).

```js
// Fibonacci: naive O(2ⁿ) -> DP O(n)
// Memoization (top-down)
function fibMemo(n, memo = {}) {
  if (n <= 1) return n;
  if (n in memo) return memo[n];
  return (memo[n] = fibMemo(n - 1, memo) + fibMemo(n - 2, memo));
}
// Tabulation (bottom-up)
function fibTab(n) {
  if (n <= 1) return n;
  const dp = [0, 1];
  for (let i = 2; i <= n; i++) dp[i] = dp[i - 1] + dp[i - 2];
  return dp[n];
}
```

**Spot DP when:** you see "number of ways", "min/max cost", "can you reach", overlapping choices.

### Classic DP patterns
```js
// 0/1 Knapsack — max value within capacity W
function knapsack(weights, values, W) {
  const n = weights.length;
  const dp = Array.from({ length: n + 1 }, () => Array(W + 1).fill(0));
  for (let i = 1; i <= n; i++) {
    for (let w = 0; w <= W; w++) {
      dp[i][w] = dp[i - 1][w]; // skip item
      if (weights[i - 1] <= w)
        dp[i][w] = Math.max(dp[i][w], values[i - 1] + dp[i - 1][w - weights[i - 1]]);
    }
  }
  return dp[n][W];
}

// Longest Common Subsequence
function lcs(a, b) {
  const dp = Array.from({ length: a.length + 1 }, () => Array(b.length + 1).fill(0));
  for (let i = 1; i <= a.length; i++)
    for (let j = 1; j <= b.length; j++)
      dp[i][j] = a[i - 1] === b[j - 1] ? dp[i - 1][j - 1] + 1 : Math.max(dp[i - 1][j], dp[i][j - 1]);
  return dp[a.length][b.length];
}

// Coin change — fewest coins to make amount
function coinChange(coins, amount) {
  const dp = Array(amount + 1).fill(Infinity);
  dp[0] = 0;
  for (const c of coins)
    for (let a = c; a <= amount; a++) dp[a] = Math.min(dp[a], dp[a - c] + 1);
  return dp[amount] === Infinity ? -1 : dp[amount];
}
```

**Common DP problems:** climbing stairs, house robber, edit distance, LIS, matrix paths, partition, palindrome substrings, word break.

## 18. Greedy Algorithms

Make the **locally optimal** choice hoping for a global optimum. Works only when the problem has the *greedy-choice property*.

```js
// Activity selection — max non-overlapping intervals
function maxActivities(intervals) {
  intervals.sort((a, b) => a[1] - b[1]); // sort by end time
  let count = 0, end = -Infinity;
  for (const [s, e] of intervals) {
    if (s >= end) { count++; end = e; }
  }
  return count;
}
```

**Examples:** coin change (canonical coins), Huffman coding, Dijkstra, Kruskal/Prim, interval scheduling.
⚠️ Greedy ≠ always correct — prove it or use DP if unsure.

## 19. Backtracking

Try all options, **undo** (backtrack) when a path fails. DFS over the solution space.

```js
// All subsets (power set)
function subsets(nums) {
  const res = [];
  function backtrack(start, path) {
    res.push([...path]);
    for (let i = start; i < nums.length; i++) {
      path.push(nums[i]);
      backtrack(i + 1, path);
      path.pop();           // undo
    }
  }
  backtrack(0, []);
  return res;
}

// Permutations
function permute(nums) {
  const res = [];
  function backtrack(path, used) {
    if (path.length === nums.length) { res.push([...path]); return; }
    for (let i = 0; i < nums.length; i++) {
      if (used[i]) continue;
      used[i] = true; path.push(nums[i]);
      backtrack(path, used);
      path.pop(); used[i] = false;
    }
  }
  backtrack([], []);
  return res;
}
```

**Examples:** N-Queens, Sudoku solver, combinations, word search, generate parentheses.

## 20. Bit Manipulation

Operate on binary representations — fast and memory-efficient.

| Op | Meaning |
|----|---------|
| `a & b` | AND |
| `a | b` | OR |
| `a ^ b` | XOR |
| `~a` | NOT |
| `a << n` | left shift (×2ⁿ) |
| `a >> n` | right shift (÷2ⁿ) |

```js
const isEven = (n) => (n & 1) === 0;          // last bit
const isPowerOfTwo = (n) => n > 0 && (n & (n - 1)) === 0;
const getBit = (n, i) => (n >> i) & 1;
const setBit = (n, i) => n | (1 << i);
const clearBit = (n, i) => n & ~(1 << i);

// Single number — every element appears twice except one (XOR trick)
function singleNumber(nums) {
  return nums.reduce((acc, x) => acc ^ x, 0);
}
```

## 22. Problem-Solving Patterns Cheat Sheet

| Pattern | Use when… |
|---------|-----------|
| Two pointers | sorted array, pairs, palindromes |
